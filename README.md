# AulaStoreChallenge
Challenge propuesto por alura para el afianzamiento de conocimiento adquirido durante los dos primeros cursos del manejo de datos

## Desarrollo
Challenge de alura para la practica de manejor de datos en el curso de analisis de datos en ONE, en el cual se aprende sobre el manejo de datos uso de Pandas y el analisis de los mismos con el fin de entregar un informa final con la sugerencia requeria spbre que tienda vender para que se pueda realizar una nueva inversión por parte del dueño
